# Support

## Getting help

For a reproducible catalog defect, documentation correction, or fork-specific enhancement, open a focused [GitHub issue](https://github.com/Alexi5000/awesome-llm-apps/issues). Include the affected path, Python version, provider or framework, commands run, sanitized error output, and the expected outcome.

For project collaboration or broader agent-engineering inquiries, use the contact path at [TechTide AI](https://techtideai.io). This repository is maintained on a best-effort basis; triage prioritizes broken repository contracts, documentation safety, and credible security concerns.

## Request routing

| Request type | Route |
|---|---|
| Broken links, catalog structure, or README corrections | Public GitHub issue |
| Example-specific installation or runtime question | The example’s README, then a focused public issue with sanitized details |
| Security vulnerability, exposed secret, or unsafe integration behavior | Follow [SECURITY.md](./SECURITY.md); do not disclose publicly |
| Contribution workflow or review expectation | Read [CONTRIBUTING.md](./CONTRIBUTING.md) |
| Community conduct concern | Use the private path described in [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) |

Do not post credentials, access tokens, private prompts, proprietary corpora, customer data, or unreported vulnerability details in public channels.
